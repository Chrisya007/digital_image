Start with the grid

A picture is a grid

Index card · pixels

A raster image is a two-dimensional grid of pixels sampled at discrete coordinates. Its spatial resolution is width by height. Zoom far into a low-resolution grid and square blocks become visible: pixelation.

Bit depth: 2n levels Size: Width × Height × Bits Per Pixel
1920 × 10802,073,600 pixels, roughly 2.07 megapixels
1-bit / 8-bit2 tones / 256 grayscale shades from 0 to 255
24-bit RGBThree 8-bit channels; 16,777,216 possible colors

A 1000 × 1000 24-bit RGB image takes 3,000,000 bytes, approximately 2.86 MB, before compression.

Source stamp MDN Web Docs · Rafael C. Gonzalez & Richard E. Woods, Digital Image Processing, 4th ed., Chapter 2.

02 · Color coordinates03 / 07

One color, different coordinates

Color has more than one address

RGB · light channels

RGB is an additive color model for screens and camera sensors. Each pixel combines red, green, and blue light intensities from 0 to 255. RGB Euclidean distance does not necessarily match human perception.

HSV · hue, saturation, value

HSV rearranges the RGB cube into a cylindrical model. Hue is color type from 0° to 360°; saturation is purity from 0% gray to 100% vivid; value is brightness from 0% black to 100% full brightness.

CIELAB · light and opponent axes

CIELAB is perceptually uniform. L* is lightness from 0 (black) to 100 (diffuse white); a* runs green to red, and b* runs blue to yellow.

ΔE=√((ΔL*)²+(Δa*)²+(Δb*)²)

03 · Fewer colors04 / 07

Choose representative colors

Making a smaller palette

Index card · quantization

Color quantization reduces the distinct colors in an image to a palette of representative colors. K-Means can select those colors from the pixels instead of choosing evenly spaced colors.

Palette-size examples
The strip below shows 8 palette slots.

Each tile represents one palette slot. Tile colors are illustrative, not calculated by K-Means.

The source describes reducing 16,777,216 possible 24-bit colors to K representative colors.

K-Means · the palette-making loop
Convert pixels from RGB to CIELAB.
Choose K initial centroids.
Assign each pixel to its nearest centroid by Euclidean distance.
Update each centroid to its assigned-pixel mean.
Repeat until centroids stop moving significantly.
Replace each pixel with its centroid color.

Smooth tonal transition

A small palette can create color banding (posterization).

04 · Spatial patterns05 / 07

Make a limited palette feel smoother

Dots that suggest more colors

Index card · dithering

Dithering scatters available palette colors in fine spatial patterns. From a normal viewing distance, the eye blends them into intermediate shades, helping reduce visible banding.

Ordered dithering compares pixel intensity against a fixed, repeating threshold grid called a Bayer matrix. The source gives 2 × 2 and 4 × 4 examples.

It is fast and produces a distinctive crosshatch texture.

Floyd-Steinberg quantizes a pixel, computes its rounding error, then shares that error with four neighboring unprocessed pixels.

e = original color − palette color

The weights add to 1; the source says average local brightness is preserved without adding palette colors.

Source stamp Robert W. Floyd & Louis Steinberg, “An Adaptive Algorithm for Spatial Greyscale” (1976), Proceedings of the Society for Information Display, Vol. 17(2), pp. 75–77 · IEEE Xplore · Bryce E. Bayer (1973)

05 · Smaller files06 / 07

Two compression paths

Two ways to pack an image

Index card · compression

Lossless compression allows exact bit-for-bit reconstruction. Lossy compression discards visual details. PNG and JPEG use different processes and suit different image content.

PNG Lossless

Predict from left and upper pixels→Store residuals→DEFLATE

PNG preserves every pixel value identically. Its DEFLATE step compresses repeated byte patterns. The source recommends PNG for sharp text, UI screenshots, diagrams, and quantized images with flat color regions or transparency.

JPEG Lossy

YCbCr + chroma subsampling→DCT blocks→Frequency quantization

JPEG is suited to natural photographs. It separates luma (Y) from chroma (Cb, Cr), halves color resolution horizontally and vertically, and applies the Discrete Cosine Transform (DCT) to 8 × 8 blocks to produce low- and high-frequency components. Frequency quantization rounds small coefficients to zero. Over-compressed sharp edges or text can show ringing and blocking artifacts.

Source stamp W3C PNG Specification · ITU-T Recommendation T.81
