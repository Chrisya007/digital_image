# PNG

PNG (Portable Network Graphics) is described as lossless: it preserves every pixel value identically. The source article describes delta filtering that predicts each pixel from its left and upper neighbors and stores the difference, followed by DEFLATE compression of repeated byte patterns. It identifies sharp text, UI screenshots, diagrams, and quantized images with flat regions or transparency as suitable uses.
