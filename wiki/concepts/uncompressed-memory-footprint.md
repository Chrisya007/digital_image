# Uncompressed Memory Footprint

The raw uncompressed size of an image is calculated as `Width × Height × Bits Per Pixel`. In the source article's example, a `1000 × 1000` 24-bit RGB image requires `3,000,000` bytes, approximately `2.86 MB`, before compression.
